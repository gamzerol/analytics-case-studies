# Analytics Case Studies

Short, business-focused analytics projects. Each one answers a single business question and fits on one page: **problem → findings → financial impact → recommendation**.

| Case study | Business question | Key result | Tools |
|---|---|---|---|
| [Marketing Channel Value](marketing-channel-value/) | Where should the next marketing dollar go? | _coming soon_ | SQL (PostgreSQL), Tableau |

Each folder contains:
- `README.md` – the one-page case study
- `sql/` – the queries behind the numbers, with a short explanation under each
- `images/` – the charts used in the case study

> All projects use public practice datasets, not employer data.
